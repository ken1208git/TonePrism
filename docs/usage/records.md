# 記録を見る（プレイ記録・アンケートの集計）

文化祭で集まった**プレイ記録**と**アンケート**を、管理ソフト（Manager）の「記録」タブで見られます。

「記録」タブは**見るだけ**のページです。ここを操作してもゲームの登録やデータが変わることはありません。安心して触ってください。

## どこにあるか

管理ソフトの左のメニューで **「記録」**（「ログ」の下）を選びます。

- **ログ**タブ … 不具合の原因さがし用の細かい動作記録
- **記録**タブ … ここ。来場者が遊んだ結果の集計

初めて開いたときは記録を読み込むので、数秒かかることがあります。

## 画面の見かた

### タイトルの下の 1 行

`全期間：プレイ 614 件・アンケート 342 件（9/4〜9/5）　/　9/9 11:58 時点`

**読み込んだ記録ぜんぶの話**です。期間を絞ってもこの件数は変わりません（絞り込みは読み込み済みのデータを数え直すだけで、読み込みそのものはやり直さないため）。下の集計と数が合わなくても正常です。

うしろの時刻は**いつ読み込んだか**です。「更新」を押すまで新しくならないので、古いと感じたら押してください。

### 上の帯（期間）

**「全期間」**と**「期間を指定」**の 2 つです。記録が 1 日ぶんしかないときは、選びようがないので帯ごと出ません。

「期間を指定」を押すと、開始日と終了日を選ぶ欄が出ます。

- **両方の日を含みます**（終了日の夜の記録も入ります）
- 終了日を先に選んでしまっても、自動で入れ替えて期間として扱います
- 選べるのは**記録がある期間だけ**です（記録のない月へは進めません）
- 日ごとのプレイ数は「時間帯ごとの盛り上がり」の見出しに出ます

- **更新** … 記録を読み直します（文化祭の途中で見るときに使います）

### 表彰

集計から**自動で賞を選びます**。部活のふりかえりや表彰式にそのまま使えます。

| 賞 | 決め方 |
| --- | --- |
| 最多プレイ賞 | 遊ばれた回数がいちばん多い |
| 満足度賞 | アンケートの平均★がいちばん高い（回答 5 件以上） |
| 熱中賞 | 1 回あたりのプレイ時間（中央値）がいちばん長い |
| 語りたくなる賞 | 遊んだあとアンケートまで答えてもらえた割合がいちばん高い |
| 満点賞 | ★5 の割合がいちばん高い（回答 5 件以上） |
| 隠れた名作賞 | プレイ回数は控えめ（全体のまん中より下）でも評価が高い |
| いちばん遊ばれた制作者 | つくったゲームの合計プレイ回数がいちばん多い |

- **同じゲームが複数の賞を取ることがあります**。軸がちがうので、そのまま出しています。
- **同率のときは母数が多い方**が勝ちます（★5 が 80% でも、10 件の回答と 5 件では重みが違うため）。それでも並んだら連名で出ます。
- **該当者がいない賞は出ません**。回答が少ない期間では賞の数が減ります。

!!! note "「続けてもう一度」を賞にしていない理由"
    ゲームを開いた行を見ると「続けてもう一度 17 回（69 回のうち）」という数字が出ます。
    同じパソコンで、前のプレイが終わってから 2 分以内に同じゲームが始まった回数です。

    これは**賞にはしていません**。1 回が数十秒で終わるゲームほど数字が伸びてしまい
    （実際、上位はどれも 1 回 30 秒以下のゲームでした）、**ゲームの中でリトライできる作品は
    そもそも数えられない**からです。そのゲーム 1 本の中で読むぶんには意味のある数字ですが、
    ゲーム同士を比べる物差しにはなりません。

### この期間の記録

最初のプレイ・最後のプレイ・いちばん忙しかった 15 分・いちばん働いたパソコンなど、ランキングには出ないけれど話のネタになる数字です。

### 概況

いちばん上のカードです。3 段になっています。

**1 段目 — プレイ回数と、時間帯のかたち**

いちばん大きい数字が、その期間に遊ばれた合計回数です。右のグラフは時間帯ごとのプレイ数で、**いちばん多かった時間だけ**数字が付きます。

**2 段目 — 3 つのメーター**

| メーター | 満杯の意味 |
| --- | --- |
| 平均評価 | ★5（満点） |
| アンケート回答率 | 遊んだ回数ぜんぶに回答がついた状態 |
| 遊ばれたゲーム | 登録したゲームが全部遊ばれた状態 |

**この 3 つだけがメーターなのには理由があります。** メーターは「満杯まであとどれくらい」を表す形なので、**満杯がはっきり決まっている数字にしか使っていません**。プレイ回数や総プレイ時間には「ここまで行けば満点」という上限がないので、輪にすると存在しない目標があるように見えてしまいます。

数えられなかったメーターは出ません（アンケートが 0 件なら平均評価のメーターは出ない、など）。

**3 段目 — そのほかの数字**

総プレイ時間・稼働したパソコン・アンケート回答数・ピーク時間帯を並べています。

### ゲーム別

並べ替えを 4 つから選べます。

- **遊ばれた回数** … 素直な人気順
- **平均★** … 評価の高い順
- **熱中度（プレイ時間）** … 1 回あたり長く遊ばれた順
- **アンケート回答率** … 遊んだあと回答まで進んだ割合の順

**行をクリックすると開いて**、そのゲームの詳しい内訳が出ます。

- ★の内訳（★5 が何件、★4 が何件…）
- 1 回あたりのプレイ時間の分布（1 分未満／1〜3 分／…）
- 遊ばれた時間帯
- 難易度・想定プレイ時間・制作者などの登録情報
- そのゲームにもらったコメント

!!! note "「未プレイ」と「参考」のしるし"
    - **未プレイ** … 登録はされているけれど、この期間に 1 回も遊ばれなかったゲームです。あえて消さずに残しています。
    - **参考** … アンケートの回答が 5 件より少なく、平均★をそのまま比べられないという印です。1 件の★5 で 1 位になってしまうのを防ぐため、並べ替えでは下に回ります。

### 時間帯ごとの盛り上がり

15 分ごとのプレイ数を、日ごとにグラフにしたものです。山が高いほど、その時間に人が集まっていました。いちばん高いところに時刻とプレイ数が出ます。

### 全体アンケート

ランチャーを終了するときに聞く「TONE 全体はどうだった？」の回答です。**ゲーム別とは別の集計**なので、ゲームのランキングには入りません。

### 切り口べつに見る

ジャンル・難易度・期生・制作者ごとにまとめた表です。1 本のゲームが複数のジャンルや複数の制作者に属することがあるので、合計は全体と一致しません。

### もらったコメント

自由記述をまとめて読めます。

## 数字を読むときの注意

### ★3 が多めに出ることがあります

アンケートは★を選ばないと送信できませんが、**画面が開いた直後は★3 にカーソルが当たっています**。そのまま決定を押すと★3 で送られるため、★3 は実際より多めに出ている可能性があります。

### 試遊テストは記録されません

サービスモードでスタッフが試した分はプレイ記録に入りません。開場前の動作確認で数字が汚れないようにしています。

### ストアの「人気」順とは別の集計です

ストアの並び順に使う「人気」は直近の回数で決まる運用の値で、この画面の集計とは別ものです。数字が違っていても問題ありません。

### プレイ時間がおかしい記録は除いています

ゲームを閉じ忘れて放置された記録などは、時間の統計から外しています（**プレイ回数には入っています**）。除いた件数がある場合は画面の下に出ます。

## 記録が出てこないとき

- **「まだ記録がありません」と出る** … その期間に遊ばれていないか、記録の保存先が違う場所を指しています。「設定」タブの保存先を確認してください。
- **ゲーム名が「不明なゲーム no.○○」になる** … 記録は残っているけれど、そのゲームの登録が削除されています。記録自体は正しいので、回数などはそのまま読めます。
