# 管理ソフト（Manager）の使い方

管理ソフト（Manager）は、展示するゲームの情報や設定を管理するスタッフ用の道具です。
ウィンドウの上にあるタブで、やることが分かれています。

| タブ | できること |
| --- | --- |
| ゲーム | 展示するゲームの追加・編集・削除・バージョンの管理 |
| ストア | 来場者の画面に表示するゲームと、その並び順を決める |
| バックアップ | データのバックアップを取る・元に戻す |
| ログ | 動作の記録を見る（不具合の原因さがしに使う） |
| 記録 | プレイ記録・アンケートの集計を見る |
| アップデート | 新しいバージョンの確認と更新 |
| 設定 | 記録の保存先やバックアップの設定など |

## ゲーム

展示するゲームを管理します。一覧の上のボタンで、追加・編集・バージョンアップ・削除ができます。

- **追加**: 「ゲーム追加」からゲームの入ったフォルダを選ぶと、TonePrism の中に取り込まれます。
- **編集**: 一覧からゲームを選んで、情報を直します。
- **バージョンアップ**: 同じゲームの新しい版を登録します。
- **削除**: 確認画面で確かめてから削除します（一覧からも、ゲームのファイルも消えます）。

!!! tip "くわしい手順はこちら"
    項目の入力や自動検出など、ステップごとの詳しい手順は
    **[ゲームの追加・編集・更新（くわしく）](games.md)** を見てください。

## ストア

来場者の「ストア」画面に出す**セクション**（ゲームが並ぶ列・棚）を作って管理します。
セクションごとに、出すゲームと並び順、見た目の形を決められます。

!!! tip "くわしい手順はこちら"
    セクションの作り方や項目の意味は **[ストアの設定](store.md)** を見てください。

## バックアップ

ゲームの登録データの**バックアップ**を取ったり、元に戻したりします。

- **手動で取る**: 「今すぐバックアップ」で、その時点のデータのバックアップを保存します。
- **自動で取る**: ゲームの追加・編集・バージョンアップ・削除、ストアやスライドの変更など、**何か変更するたびにその直後**に自動でバックアップを取ります（設定タブの「変更があったら自動でバックアップする」で ON/OFF）。同じ起動中のバックアップは最新の 1 つにまとめられ、保持する世代数は「起動（編集セッション）」単位で数えます。
    - **進捗は画面下のバーに出ます（操作はそのまま続けられます）**: バックアップ中は画面下のバーに「バックアップ中... ／ 進捗 ／ 中止」が出ますが、**待たずにそのまま次の作業を続けられます**。連続でいくつも変更したときは、最後にまとめて 1 回だけ取り直されます。
    - **「中止」**: バックアップを後回しにしたいとき（共有サーバーが混んでいる等）に押せます。**変更したデータ自体は保存済み**で、バックアップだけが止まります。止めると下のバーに「⚠ ゲームファイルが未バックアップです」と**「今すぐバックアップ」**ボタンが出るので、押せば取り直せます（次に何か変更しても自動で取り直されます）。
- **履歴**: いつ・どのパソコンで取ったか、サイズなどが一覧で見られます。
- **元に戻す（復元）**: 履歴から選んで「復元」。**戻す前に、来場者向けの画面（Launcher）をすべて閉じてください**という注意が出ます。
  実行すると今のデータはバックアップに退避され、選んだバックアップに入れかわります。
    - **その時点に丸ごと戻ります（DB＋ゲームファイル）**: 控え（バックアップ）のある世代を復元すると、登録データ（DB）だけでなく**その時点のゲームファイル（`games`）・初回説明の画像（`guide`）も一緒にその時点へ戻ります**。DB とゲームの中身が**同じ時点でそろう**ので、別の時点を復元したときに起きる「登録はあるのに起動できないゲーム」が出にくくなります。控えの無い古い世代は登録データだけの復元になります（確認画面に表示されます）。

        !!! warning "この時点より後に追加したゲームは消えます"
            ゲームファイルも戻すと、**その時点に無いファイル（＝復元後に追加・変更したゲーム）はディスクから削除**され、足りないファイルは控えから戻ります（変わっていないファイルはそのまま）。たとえば「先週のバックアップ」を復元すると、今週追加したゲームのファイルは消えます。<br>**ただし削除の前に、いまの状態（登録データ＋ゲームファイル）が自動で退避されます**（復元前の `safety_*.db` として履歴に残り、古い退避は自動で消えます）。やり直したいときは、その **`safety_*.db` を「復元」すれば、登録データもゲームファイルも元に戻せます**。万一この退避に失敗したときは、安全のため**ゲームファイルには触れず、登録データだけを復元**します。
- **ゲームファイル・初回説明の画像も自動でバックアップする**: バックアップを取ると、登録データ（DB）に加えて**ゲームファイルの `games` フォルダと初回説明の `guide` 画像も同時にバックアップ**を取ります。**中身が同じファイルは 1 個にまとめて保存**するので（別ゲームが同じランタイムを積んでいても、版違いフォルダが重複していても 1 個）、**ディスクは見た目どおり小さく済みます**（多くの世代を持っても、増えるのは新しく加わったファイルの分だけ）。「最終アセットバックアップ」に最後に取った日時と**バックアップ全体の実使用量**が出ます。設定タブで取得の ON/OFF と世代数を変えられます。
- **整合性チェック**: 「整合性チェック」ボタンで、登録データ（DB）とディスク上のゲームファイル・初回説明の画像の**ズレ**（登録はあるのに起動できないゲーム／画像の欠落など）をその場で確認できます。とくに**別の時点のバックアップを復元したあと**、足りないフォルダを手で補ってから「直ったか」を確かめるのに使います（**Manager の再起動では再チェックされません**。このボタンを押してください）。

!!! note "バックアップの保存場所"
    バックアップは保存先フォルダの中に **`asset_pool`（ファイルの実体を中身ごとに 1 個だけ置く場所）** と **`asset_snapshots`（各回のバックアップの「目録」）** という形で入ります。エクスプローラーで見えるサイズも、サーバーの容量計算も、**実際の使用量（重複を除いた分）どおり**に出ます（ハードリンクのように「見かけだけ大きい」という現象は起きません）。

!!! note "最初の1回だけ時間がかかります"
    ゲームファイル（`games`）・初回説明の画像（`guide`）のバックアップを**取り始めた最初の1回**は、全ファイルを読み込むため時間がかかり、共有サーバーへの通信も増えます（2回目以降は変わった分だけ読むので速くなります）。アップデート直後は、混雑しない時間帯に「今すぐバックアップ」を一度押しておくと安心です。

!!! info "ゲームファイルも一緒に戻ります"
    「復元」は、登録データ（toneprism.db）だけでなく、**その時点のゲームファイル（`games`）・初回説明の画像（`guide`）も一緒にその時点へ戻します**（控えのある世代のとき）。一緒に戻るので DB とゲームの中身が同じ時点でそろい、別の時点を復元したときの「登録はあるのに起動できないゲーム」が起きにくくなります。

    控えの無い古い世代を復元したときは登録データだけが戻り、いまの `games` と DB の時点がズレて「登録はあるのに起動できないゲーム」が出ることがあります。その場合の内容と直し方は、復元のあとに出るレポートで案内します。

    復元のあと、管理ソフトが自動で**整合性チェック**を行い、ズレがあれば内容（起動できないゲーム／ディスクに無いバージョン／サムネ・背景画像の欠落／**初回説明スライドの画像の欠落**／登録に無い余分なフォルダ）と**直し方の手順**を表示します。ゲームファイルも一緒に戻した場合は、**戻せたファイル数・控えに実体が無く戻せなかったファイル**もレポートに出ます。控えに実体が無くて戻せなかったゲームは、別の世代を「ゲームファイルも一緒に復元」でやり直すと直ることがあります。

    なお「データベースのリセット」は登録データと `games` フォルダの両方をまっさらにするため、復元のようなズレは起きません。

## ログ

来場者向けの画面（Launcher）と管理ソフト（Manager）の**動作の記録**を見られます。
どちらの記録か、また重要度（エラー／注意／情報）で絞り込めます。不具合の原因さがしに使います。

## 記録

文化祭で集まった**プレイ記録**と**アンケート**の集計を見られます。どのゲームが何回遊ばれたか、★がいくつだったか、どの時間に人が集まったかを、グラフと一覧で確かめられます。**見るだけ**のページなので、操作してもデータは変わりません。

結果を HTML ファイルに書き出して、部員や先生に配ることもできます。

!!! tip "くわしい見かたはこちら"
    並べ替えや★の読み方、書き出しの手順は
    **[記録を見る（プレイ記録・アンケートの集計）](records.md)** を見てください。

## アップデートの適用

新しいバージョンの確認と更新をします。今のバージョンが表示され、新しい版があると知らせてくれます。

「今すぐアップデート」を押すと、こう進みます。

1. 管理ソフトが**いったん閉じて新しい版で開き直す**ことを、先にお知らせします（来場者向けの画面が開いていたら閉じるよう案内が出ます）
2. 新しい版を自動でダウンロード（進み具合のバーが出ます）
3. 中身を入れかえ
4. 管理ソフトがひとりでに開き直して、**結果のお知らせ**が出ます

お知らせは 3 種類あります。

- **「✓ アップデート完了」** … 新しい版になりました。そのまま使えます
- **「✗ アップデート未完了」** … 入れかえの途中で失敗しました。**ゲームのデータは無事です**。「アップデート」タブからもう一度お試しください。それでも失敗するときは、`logs` フォルダの中の記録ファイルをそえて開発者に連絡してください
- **「アップデート結果を確認できません」** … 成功したかどうかを判断できませんでした（記録ファイルが壊れていた場合など）。**ゲームのデータは無事です**。「アップデート」タブでバージョンを確認し、古いままならもう一度お試しください

!!! info "「前回のアップデートが完了していません」が消えないとき"
    失敗のお知らせは、**次に更新が成功するまで残ります**（時間では消えません）。
    そのまま「今すぐアップデート」をもう一度押せば、成功した時点で消えます。

    管理ソフトを配布 zip の `Install.bat` で入れ直して直した場合は、
    `Install.bat` は入れ直しが最後まで成功したときにこの記録を掃除するので、こちらも自動で消えます。

!!! warning "更新中の注意"
    更新の間、管理ソフトはいったん閉じます（先のお知らせのとおり）。
    ゲームのデータは守られるので、そのまま開き直すのを待ってください。

## 設定

記録の保存先やバックアップ、アンケートの設定などを調整します。

- **変更するとその場で保存されます**（「適用」ボタンを押す必要はありません）。数値や入力欄は、欄から離れたときに保存されます。
- 「記録の保存先」は、来場者の画面・管理ソフトなど**すべての記録をまとめて入れておくフォルダ**を指定します。

### アンケート

来場者にアンケートを出すかどうかを切り替えます。**2 つを別々にオン／オフできます。**

| 設定 | いつ出るか | どのくらいの頻度か |
| --- | --- | --- |
| ゲーム終了時のアンケート | ゲームを 1 本遊び終えたとき | **毎回**（多い） |
| 退出時のアンケート | 来場者が席を離れるとき | 退出のたびに 1 回 |

- **切り替えると、各 PC のランチャーにすぐ反映されます**（ランチャーを再起動する必要はありません）。
- **混雑してきたら「ゲーム終了時のアンケート」だけをオフ**にすると、回転を落とさずに済みます。退出時のアンケートは頻度が低いので、そのままでも大きな負担にはなりません。
- 来場者は 1 件ずつ「答えない」で断ることもできます。**断られた回答は保存されません。**
- **オフに戻し忘れに注意**してください。混雑が落ち着いたらオンに戻さないと、それ以降のアンケートが 1 件も集まりません。
